BilliEnoughFakepixel (BEF)

A Minecraft Fabric client-side mod focused on Hypixel-style SkyBlock gameplay, dungeon features, quality-of-life improvements, and mobile-friendly settings.

✨ Features

⚔️ Dungeon Features

- Custom Spirit Leap GUI with dungeon class colors.
- Terminal highlighting and solvers.
- Dungeon score and secrets overlays.
- S+ score notification.
- Blood Room ready notification.
- Boulder, Silverfish, Three Weirdos, and Teleport Maze solver features.
- Starred mob highlighting.
- Spirit Bow tracer.
- Dungeon map and secret overlay options.
- Epic, Legendary, and Mythic item salvage protection settings.

🐉 Floor 7 & Master Mode 7

- Terminal waypoints.
- Terminal and device progress tracker.
- Wither highlighting.
- M7 Dragon highlighting.
- Relic waypoints.
- Custom terminal GUI options.

🧩 Experimentation Table

- Chronomatron solver.
- Ultrasequencer solver.
- Superpairs solver.
- Miss-click prevention option.

👑 Slayer Features

- Voidgloom beacon waypoint.
- Slayer miniboss spawn alert.
- Slayer health display.
- Boss timer.
- Blaze pillar notification.
- Blaze attunement display.

🛠️ Quality of Life

- Always sprint.
- Fullbright option.
- Reduced block-breaking particles.
- Etherwarp overlay, sounds, and zoom.
- Hide selected visual effects.
- Item animation and scaling options.
- Equipment overlay.
- Wardrobe and equipment key shortcuts.
- Middle-click menu support.
- Ender Node highlighting.
- Reforge helper option.
- Additional visual and gameplay settings.

📱 Mobile-Friendly Options

- MobileGlues / GL4ES safe-mode option.
- Low-end mobile fast-mode option.
- Configurable visual settings.
- Designed with mobile launcher users in mind.

Actual performance and renderer compatibility may vary by device and configuration.

🎮 Controls

Control| Action
Right Shift| Open BEF settings
"/bef"| Open BEF settings
"/billienoughfakepixel"| Open BEF settings
Z| Etherwarp zoom

Keybinds can be changed in Minecraft's Controls menu.

📥 Installation

1. Install Minecraft Java Edition 1.21.1.
2. Install Fabric Loader.
3. Install Fabric API for Minecraft 1.21.1.
4. Download the latest BEF ".jar" from Releases.
5. Place the JAR inside your Minecraft "mods" folder.
6. Launch Minecraft using the Fabric 1.21.1 profile.

⚙️ Requirements

- Minecraft Java Edition 1.21.1
- Java 21
- Fabric Loader 0.15.11 or newer
- Fabric API for Minecraft 1.21.1

🧪 Development Status

BEF is under development. Some features may need additional testing and improvements. Compatibility and performance should be tested before relying on features during important gameplay.
